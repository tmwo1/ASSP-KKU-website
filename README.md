## 🚀 كيفية تفعيل الاستضافة (GitHub Pages Activation)

الموقع جاهز تماماً للنشر المباشر عبر **GitHub Pages** بخطوات بسيطة:
1. اذهب إلى تبويب **Settings** (⚙️ الإعدادات) أعلى هذا المستودع.
2. من القائمة الجانبية اختر **Pages**.
3. تحت قسم **Build and deployment**:
   - يمكنك اختيار **Deploy from a branch** (الفرع: `main`، المجلد: `/root`).
   - أو اختيار **GitHub Actions** للاستفادة من النشر المؤتمت الفوري عبر ملف العمل المرفق (`.github/workflows/deploy.yml`).
4. اضغط **Save** وسيعمل الموقع فوراً على الرابط المباشر.

## ✨ المميزات والوظائف الرئيسية

### 1. واجهة الموقع العام (`index.html`):
- **عرض الفعاليات والورش المعتمدة**: بطاقات تفاعلية مع تفاصيل الموقع، التوقيت، وحالة المقاعد.
- **استمارة تسجيل مستقلة لكل فعالية**: ربط كل فعالية بنموذج Google Form خاص بها من قبل الإدارة.
- **إخفاء عدد المقاعد عند التسجيل المفتوح**: للمحافظة على خصوصية وسلاسة التسجيل.
- **نظام التحقق من صحة الشهادات**: إدخال البريد الإلكتروني المسجل واسم الفعالية مع ظهور إفادة استلام الطلب ("الرد من ٤ إلى ٨ أيام عمل").
- **مكتبة المعرفة وأدلة السلامة المهنية**: استعراض وتحميل مباشر للكتيبات والأدلة الإرشادية.

### 2. بوابة التحكم الإدارية (`admin.html`):
- **حماية أمنية برمز سري (PIN)**: دخول مقتصر على المشرفين والإداريين.
- **إدارة الفعاليات**: إضافة وتعديل وحذف الفعاليات، وتخصيص رابط Google Form لكل فعالية.
- **طلبات استعلام الشهادات**: متابعة طلبات الطلاب، تصدير CSV، وتغيير الحالة والرد بالبريد الإلكتروني.
- **إدارة المعرفة (الأرشيف السري)**: رفع ملفات ووثائق إدارية من جهاز المشرف وحفظها وتنزيلها بأمان.
- **إدارة كتيبات ومكتبة المعرفة**: رفع ملفات من جهاز المشرف وإتاحتها للزوار والطلاب للتحميل المباشر.
- **إدارة الفرق وأعضاء الجمعية**: تنظيم قادة الجمعية وقادة اللجان وأعضاء فرق العمل.
- **توقيت وبوابة التسجيل والشريط الإعلاني**: تحكم كامل بمؤقت التسجيل والإعلانات العلوية.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: HTML5, Tailwind CSS (CDN), Modern Vanilla JavaScript (ES6+).
- **Icons & Visuals**: SVG Icons, Official University & ASSP Identity Assets.
- **Storage**: Client-side Storage (`localStorage`) with Base64 File Caching.
- **Deployment**: GitHub Pages / GitHub Actions / Static Web Hosting.
